Validation Methodology

Data Collection (2020-2024)

Gathered 1,275 trading days of historical S&P 500 data including price, volume, technical indicators, news sentiment, and economic data.

1,275 samples
Feature Engineering

Created 91 engineered features combining technical indicators, sentiment analysis, and economic indicators.

91 features
Train/Test Split (70/30)

Split data chronologically with 70% training (893 days) and 30% testing (382 days) to prevent data leakage.

893 train / 382 test
Model Training (XGBoost)

Trained XGBoost gradient boosting classifier with hyperparameter optimization using grid search.

XGBoost
Walk-Forward Validation

Validated on 382-day test set using proper time-series methodology with no look-ahead bias.

71.20% Accuracy
Data Leakage Prevention
  • Chronological Split: Training data comes before test data (no future information leakage)
  • No Look-Ahead: All features calculated using only past data
  • Proper Validation: 30% test set (382 days) provides reliable accuracy estimate
  • Time-Series Aware: Walk-forward validation respects temporal order
